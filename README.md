# Kitadachs

Willkommen bei **Kitadachs** – dem Tool für **Gruppenzuordnung** und **Forecast** in Kitas.

!!! tip "Was ist Kitadachs?"
    - Kinder gruppenweise planen  
    - Auslastung und Altersstruktur im Blick  
    - Forecast für kommende Monate

## Features
- **Drag & Drop**-Gruppenzuordnung
- **Forecast** nach Stichtag/Quartal
- **Export** (CSV/ICS geplant)
