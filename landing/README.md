# Kitadachs Landing Page

Eine moderne, responsive Landing Page für die Kitadachs Kindergarten-Verwaltungsanwendung.

## 🚀 Features

- **Moderne Design**: Clean, professionelles Design mit Gradienten und Animationen
- **Responsive**: Optimiert für alle Geräte (Desktop, Tablet, Mobile)
- **Interaktiv**: Smooth Scrolling, Hover-Effekte und Animationen
- **Performance**: Optimiert für schnelle Ladezeiten
- **Accessibility**: Barrierefreie Navigation und Interaktionen

## 📁 Struktur

```
landing/
├── index.html          # Haupt-HTML-Datei
├── styles.css          # CSS-Styles mit modernen Features
├── script.js           # JavaScript für Interaktivität
└── README.md           # Diese Datei
```

## 🎨 Design-Features

### Farben
- **Primary**: Gradient von #667eea zu #764ba2
- **Secondary**: Gradient von #f093fb zu #f5576c
- **Text**: Verschiedene Grautöne für Hierarchie
- **Background**: Weiß mit subtilen Grautönen

### Typography
- **Font**: Inter (Google Fonts)
- **Hierarchy**: Klare Größenunterschiede
- **Readability**: Optimierte Zeilenhöhen

### Animationen
- **Scroll-Animationen**: Elemente erscheinen beim Scrollen
- **Hover-Effekte**: Interaktive Karten und Buttons
- **Parallax**: 3D-Effekte im Hero-Bereich
- **Typing-Effekt**: Animierter Text im Titel

## 📱 Responsive Breakpoints

- **Desktop**: > 1024px
- **Tablet**: 768px - 1024px
- **Mobile**: < 768px
- **Small Mobile**: < 480px

## 🔧 Technische Details

### CSS Features
- CSS Custom Properties (Variablen)
- CSS Grid und Flexbox
- CSS Animations und Transitions
- Media Queries für Responsive Design
- CSS Gradients und Shadows

### JavaScript Features
- Intersection Observer für Scroll-Animationen
- Throttled Scroll Events für Performance
- Mobile Navigation Toggle
- Smooth Scrolling
- Counter Animationen
- Ripple Effects

### Performance
- Optimierte Bilder und Icons
- Minimierte CSS und JavaScript
- Lazy Loading für Animationen
- Throttled Event Listeners

## 📝 Anpassungen

### Farben ändern
Bearbeiten Sie die CSS-Variablen in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    /* ... */
}
```

### Inhalte anpassen
Bearbeiten Sie die entsprechenden Bereiche in `index.html`:
- Hero-Section: Titel und Beschreibung
- Features: Feature-Karten
- About: Über-uns-Text
- Contact: Kontaktinformationen

### Animationen deaktivieren
Kommentieren Sie die entsprechenden JavaScript-Funktionen in `script.js` aus.
